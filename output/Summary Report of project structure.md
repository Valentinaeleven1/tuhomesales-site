# Summary report of project structure

## Project purpose
This workspace is being used to plan and develop a simple humanitarian rescue technology concept focused on emergency signal detection and search support.

## Current structure
- output/ contains finished planning documents and deliverables
- workflows/ is reserved for repeatable project processes and step-by-step workflows
- resources/ is reserved for reference documents, templates, and supporting material

## Current planning approach
The project is being developed in stages:
1. Define the rescue problem clearly.
2. Create simple, realistic MVP concepts.
3. Choose the easiest path to a first prototype.
4. Keep the scope focused on usefulness rather than complexity.

## Recommended next step
Create a first MVP plan for the phone-based rescue beacon concept and then build a prototype with a simple map and detection workflow.
