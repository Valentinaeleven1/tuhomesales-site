# Drone Payload Quick-Start Mission Checklist

## Before sending the kit
- Confirm the Raspberry Pi payload is fully assembled and tested.
- Verify the rescue program runs and logs GPS plus signal readings.
- Ensure the payload is secure in its case and ready for mounting.
- Include a short instruction note with startup commands.

## Hardware pack contents
- Raspberry Pi 4 Model B or Raspberry Pi Zero 2 W
- USB GPS receiver
- Signal sensor module (RTL-SDR or Bluetooth/Wi-Fi adapter)
- MicroSD card with Raspberry Pi OS and program loaded
- Power bank or 5V power supply
- Cables, mounting straps, padding

## Mounting on the drone
- Attach the payload to the drone using a lightweight bracket or straps.
- Keep the unit centered or balanced to avoid flight instability.
- Secure all cables and protect components from vibration.
- Confirm the total payload weight is within the drone’s safe limit.

## Startup procedure for the operator
1. Connect the power bank to the Raspberry Pi.
2. Power on the drone (if needed) and the Pi.
3. Wait for the Raspberry Pi to boot.
4. Start the program with the supplied command.
5. Verify the program is recording GPS location and sensor data.

## Mission launch steps
- Confirm the drone has GPS lock and a clear flight path.
- Start the mission from the drone controller.
- Monitor the payload status if possible.
- Keep the drone at a safe altitude for the detection area.

## During the mission
- Note the mission start time.
- Record any observations or changes in signal strength.
- If the payload supports live upload, verify data transfer.
- If not, plan to retrieve the payload data after the flight.

## After the mission
- Land the drone safely.
- Power down the Raspberry Pi.
- Remove the payload and secure the components.
- Retrieve the log files from the Raspberry Pi.
- Upload or send the data for analysis.

## Important reminders
- Do not overload the drone with extra weight.
- Keep the payload stable and protected from vibration.
- Use the test mission first to confirm the workflow.
- Prioritize safety and clear communication with the drone operator.
